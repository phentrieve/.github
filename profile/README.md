# Phentrieve

Open-source tools that turn clinical text into [Human Phenotype Ontology](https://hpo.jax.org/) (HPO) terms, plus the data and annotation tools to measure how well that works.

**[Try it at phentrieve.org](https://phentrieve.org/)** · [Documentation](https://phentrieve.github.io/phentrieve/)

## Projects

| | |
|---|---|
| **[phentrieve](https://github.com/phentrieve/phentrieve)** | Finds HPO terms in free-text notes, in several languages. Python library and CLI, REST API, MCP server and web app. |
| **[phentrieve-data](https://github.com/phentrieve/phentrieve-data)** | Versioned, checksummed HPO index bundles, so every result can be traced to an exact ontology release. |
| **[ontotator](https://github.com/phentrieve/ontotator)** | Self-hosted service where several people annotate texts with ontology terms and review each other's work. |
| **[ontospan](https://github.com/phentrieve/ontospan)** | One format for ontology annotations on text spans, shared by all of the above. |

## Research use only

Phentrieve is not a medical device. Do not use it for diagnosis, treatment or other clinical decisions.
